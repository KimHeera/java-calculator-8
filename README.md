## 💻 기능 목록

- [ ] 입력 문자열이 **null**이거나 **빈 문자열**일 경우 0을 반환한다.
- [ ] 문자열에 포함된 숫자를 쉼표(`,`) 또는 콜론(`:`) 구분자로 분리하여 합을 계산한다.
- [ ] 문자열 앞부분의 `//`와 `\n`을 사용하여 **커스텀 구분자**를 지정할 수 있으며, 이 구분자로 숫자를 분리하여 합을 계산한다.
- [ ] 구분자가 연속되거나 문자열의 시작/끝에 구분자가 위치하는 등 유효하지 않은 입력은 **예외 처리하지 않고** 처리한다. (기능 요구사항에 명시되지 않은 부분은 스펙으로 간주)
- [ ] 숫자 이외의 문자가 포함되거나 **음수**가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] `IllegalArgumentException` 발생 시 애플리케이션은 정상적으로 종료된다.
